# P1 experimental source

This directory publishes the preserved P1 research workspace. Run Cargo from `experimental/p1`.
The snapshot is experimental, not a production memory service. Its old README/HANDOFF/publication
restrictions and absolute tool-directory examples are historical records; the owner's 2026-11-22
integration authorization supersedes the old private-only publication instruction, not the safety gates.
The repository's existing MIT LICENSE is unchanged. Dependency licenses remain their own.

See [current implementation status](../docs/IMPLEMENTATION_STATUS.md) and
[integration provenance](../docs/integration/20261122/README.md). No production content, service
identity, Native Terminal/A3/R12 or Protected Witness capability is enabled by publishing this source.
