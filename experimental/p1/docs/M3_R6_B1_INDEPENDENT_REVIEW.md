# R6-B1 独立审查记录

审查代理 `/root/r6_luna_review`，只读检查，未修改源码、未运行构建或测试。其模型身份无法核验为 Luna High。按用户要求，该指定模型签核项目为 **NOT TESTED**。本记录描述实际取得的独立源码意见和修复。

| 意见 | 修复及验证 |
|---|---|
| 任意 Child 加调用方 incarnation 可以错配退出证明 | 移除该构造入口。OwnerProcess 只启动固定的自有测试入口，以该 Child 继承的 stdout 验证父进程生成的 nonce、安装、Realm 和 incarnation，实际 wait 后构造私有证明。不同存储的证明互换测试拒绝。 |
| clean 布尔值没有完整停机证据 | 新增不可变 stop_receipt，绑定实例、安全版本、schema 和元数据账本摘要。恢复在同一写事务重查并消费该证明。篡改停止后的账本会拒绝恢复。 |
| 新存储未验证旧文件和 SQLite sidecar | W1 句柄枚举根目录，拒绝已有 WAL、SHM、旧库和未知根条目。密文／包装目录必须为空。重新打开核对目录身份和所有登记对象，未知对象保持阻断。 |
| 调用者时间可能绕过过期 Grant | Application 移除每请求时间参数。实际授权统一取 OS 时间，T1 再检查。测试在发布后等待到期并断言零 Receipt。 |
| 已结算但当前无读取资格的数据导致无法停止 | 将结算完整性和当前读取资格分别核对。已撤权数据可保留及正常停止，新实例仍拒绝该主体写入。 |
| 新增 NTFS 枚举解析需专项边界测试 | 针对截断、奇数字节数、非法 next offset、超大偏移和不合法 UTF-16 的用例拒绝解析。真实 NTFS 枚举同时用于正常写入和恢复测试。 |
| 复用范围容易被扩大描述 | 报告限定为 R4 授权／Closing／排序门和 R5 规范依赖绑定共用代码。完整 R3 会话认证、R5 多类命令和正文释放另行验收。 |

最终只读复审未发现根命名空间检查或目录记录解析的新阻断问题。复审代理未自行执行测试，测试 PASS 以保存的运行日志为依据。

当前保留的条件包括 OS wall-clock 与完整本地回滚域的局限、标准 SQLite VFS 的生产验收缺口、无强密钥销毁保证和指定 Luna High 签核未执行。恢复测试证明一次受控子进程干净退出、重开、恢复及继续写入；尚未证明多轮 owner 交接和重复停机／恢复链。完整 R6 仍为 NOT READY。
