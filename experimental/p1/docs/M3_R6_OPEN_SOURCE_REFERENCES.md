# R6 开源调研

查阅日期为 2026-11-19（Asia/Shanghai）。固定版本用于设计对照。除基线已锁定的 bundled SQLite 外，本次提交不安装这些项目、不复制其实现，也未运行其上游测试。

R6-B1 延续上述固定版本。实现选择复用本仓库 W1、W2、R6 AEAD 及 R4/R5 共享的安全门，Cargo.lock 未新增依赖。SurrealKV 的文件／Key 关联启发用于 publication 和清点，通用凭据框架不进入运行链。SQLite 的单事务边界落实为同库 T1，外部文件发布采用持久意图协调。NtQueryDirectoryFile 的调用约定与 FileNamesInformation 的 4 字节对齐规则依据 Microsoft 官方定义，并增加了畸形记录拒绝测试。[NtQueryDirectoryFile](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/ntifs/nf-ntifs-ntquerydirectoryfile)、[FILE_NAMES_INFORMATION](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/ntifs/ns-ntifs-_file_names_information)、[FILE_INFORMATION_CLASS](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/wdm/ne-wdm-_file_information_class)。
