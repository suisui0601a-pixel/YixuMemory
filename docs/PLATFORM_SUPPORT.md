# 平台验证矩阵

记录日期：2026-11-03。本文区分部署设计目标、实际原型测试和生产安全验收。当前可验证的原型测试范围限定为 **Windows + NTFS**，不是全部操作系统或文件系统的支持声明。

| 平台 / 文件系统 | 当前验证状态 | 证据与适用范围 | 不作出的承诺 |
|---|---|---|---|
| Windows + NTFS | 已进行实际测试；本地 M3-B 合成持久化原型限定范围独立审查通过 | 隔离装配、真实 SQLite 事务、合成密文重启读取、CAS、幂等、部分进程终止恢复；版本和环境以对应本地报告为准 | 不代表所有 Windows 版本、文件系统或生产部署；不代表安全目录发布、真实 KeyVault/Witness、强删除或断电验收 |
| Windows + exFAT | NOT TESTED | 不是已验收数据库或安全文件操作环境 | 不作兼容性及安全性保证，不能套用 NTFS 测试结论 |
| Linux | NOT TESTED / SKIPPED | M3-C1 未执行；Ubuntu 22.04.5 / Kernel 5.15 环境仅做只读预检，缺少 C 构建依赖后停止；项目决定本阶段不继续投入 Linux 实机测试 | 没有 P1 Linux 编译、运行、文件系统竞争或恢复验收证据；Kernel 版本和参考源码存在均不证明可用 |
| macOS | NOT TESTED | 没有 macOS 原型编译或运行记录 | 不声明 Intel 或 Apple Silicon 兼容性，不作安全性承诺 |

未测试不等于永久不支持，未来可以重新安排跨平台验证。现阶段不再为 M3-C1 在现有生产服务器安装系统构建依赖，也不部署外部测试环境。

## 证据的层次

M3-B 是未公开的本地合成实验，不是本公开仓库已发布的运行内核。本次仅同步文档，没有同步 P1/M3 源码、私有测试后端、密钥或原始服务器日志。

公开 P0 的 GitHub Actions 在 Ubuntu 上执行 Python 契约测试和 SQLite 探针；这些结果可证明相应公开检查通过，不能替代未公开 P1 Rust 内核或 M3-C1 的 Linux 编译、文件系统与安全验收。文档 PR 的 CI 通过也不会改变上表。

合成原型 PASS 不等于生产级安全认证。生产内容入口仍关闭，真实用户内容、完整 KeyVault/Witness、强删除、备份防回滚和物理断电仍未验收。

部署文档中的 desktop/container/server/postgres 以及 Windows/macOS/Linux/NAS/VPS 描述保留为设计目标，不升级为当前兼容性承诺。具体测试汇总见[测试状态总记录](TEST_STATUS.md)。
